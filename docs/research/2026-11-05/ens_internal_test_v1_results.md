## 解读与边界

1. 在内部 test 上，ENS 把正常误报降了 28%，故障召回从 97.11% 升到 98.00%，误报和召回同时改善。降幅主要来自悬停（287 → 171），尤其是 HIL 悬停后段（105 → 34）。
2. 和 train 内交叉验证不同：在 test 上，悬停后段的 GPS 和 Baro 召回也没有下降。
3. SIL 悬停后段改善有限（113 → 95），与交叉验证的观察一致。
4. 这是一次性的窗口级评估，单个 M0 checkpoint、单个 GBT 拟合，不做显著性推断。事件级、连续流、Real 迁移和在线部署都还没有评估。
5. 融合规则是在 seed-42 那一轮看过源 val 之后定的，test 结果确认的是这个已冻结的规则。
