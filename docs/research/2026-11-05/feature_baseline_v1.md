# 窗口统计特征基线（全源 train/val）

日期：2026-11-05。CPU，梯度提升树，无神经网络训练，不读 test/Real。脚本与结果：`artifacts/feature_baseline_v1_20261105/`。

## 设计

- 特征：每通道窗内均值、标准差、最小、最大、一阶差分绝对均值，共 130 维；直接由未归一化缓存计算。
- 模型：HistGradientBoosting（400 轮，lr 0.05，31 叶，L2 1.0，random_state 0），超参在看结果前固定，未调。
- 采样权重：与 M0 B 相同的两种正常来源各半、正常总质量 83051。
- 两个训练人口：原始 train 162069；train + H1 补窗 19573。
- 评估：完整源 Val 34710，固定 0.5。集成 = M0 B 与 GBT 概率平均（看到 GBT 结果后才加的，属于事后探索）。

## 结论

1. 只换表示（窗口统计 + 树模型）、不改训练人口，悬停后段误报就从 222 降到 140，全正常误报 417 → 303，而故障总召回不降。说明 M0 的问题主要在表示，不在覆盖。
2. M0 与 GBT 概率平均后，全正常误报 417 → 300，故障 TP 16428 → 16487；六类中只有 GPS（−7）和 Baro（−1）略降。这是本项目第一次在源 val 上同时降低误报且不损总召回。
3. 补窗在 GBT 上依然是取舍：误报更低，召回下降。补窗不是主要方向。
4. 改善集中在 HIL：6 个 HIL 后段正常案例的 FPR 从 0.71–1.00 降到 0–0.32，SIL 案例基本没变（0.55–1.00）。SIL 的悬停后段误报原因还需单独看。

## 限制

- 单次拟合，无 seed 或折间不确定性；源 val 已被多轮开发反复使用。
- 集成方式是看到 GBT 结果后决定的，须在独立验证上确认，不能作为已验证结论。
- 非神经网络，不能直接替代在线模型；它说明的是"窗口统计里有 M0 没用上的信息"。
