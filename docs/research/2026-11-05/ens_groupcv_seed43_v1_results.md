# ENS 独立确认：seed 43 重跑 train 内 3 折

日期：2026-11-05。配置：`configs/experiments/ens_groupcv_seed43_v1.json`（运行前冻结）。产物：`artifacts/ens_groupcv_seed43_v1_20261105/`。

## 设置

- 折划分与 feature_groupcv_v1 相同。
- M0 使用 seed 43：初始化沿用生成 seed-42 锚点的同一流程，即用 seed 构建旧 KG 模型，再把编码器和分类头映射过来。用这条流程以 seed 42 重建，digest 与原锚点一致（a68551099cba，在服务器上核对）。seed 43 的 digest 为 4ab14511259f。采样器和 loader 的种子随 seed 改变，训练配方与 M0 B 相同。服务器为 autodl_UAV，best epoch 依次为 37/47/31。
- GBT 的特征和超参不变，random_state 改为 1。
- 判据沿用 m0s_stats_branch_v1 的 a–d，看过结果后没有修改。

## 结论与边界

1. M0 与窗口统计 GBT 的概率平均，在 train 内按配对组 3 折、两个 seed 下，都把正常误报降低约 36%，故障总召回不降，悬停后段之外每类召回也不降。
2. 代价集中在悬停后段的 GPS 和 Baro：M0 在这一层同时把约 91% 的正常窗判为故障，这部分召回本身就不可靠。
3. SIL 悬停后段误报的改善有限（约 600 → 500），HIL 的改善明显（约 533 → 240）。
4. 尚未做：内部 test 与 Real 上的评估、连续流事件级评估、在线部署。融合方式（概率平均、阈值 0.5）是在 seed-42 那一轮看过源 val 结果后决定的；seed 43 只确认了它在 train 内的稳定性。
