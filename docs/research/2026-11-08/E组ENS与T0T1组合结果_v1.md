# E 组：ENS（MSTCA + 窗口统计 GBT）叠加 T0/T1，train CV 零训练分析

日期：2026-11-08
协议：`configs/experiments/e_ens_t_cv_v1.json`（commit 30a056d，在看到任何结果之前冻结）
脚本：`scripts/research/e_ens_t_cv.py`
产物：`artifacts/e_ens_t_cv_v1/evaluation.json`

本轮只用 train CV 的 held-out 预测，没有训练任何模型，也没有读取 val、内部 test 或 Real 数据。

## 设置

**参与比较的臂**

- T0：现行基线。
- T1：固定训练 100 轮。
- GBT：`feature_groupcv_v1` 中逐折重拟合的 130 维窗口统计 GBT，所有 seed 共用同一组预测。
- E0：T0 与 GBT 的故障概率取平均。
- E1：T1 与 GBT 的故障概率取平均。

**评估口径**：与 W 组一致。

- 主指标为 FP@R97，按 seed 计算相对 T0 的比值，再对 5 个 seed 取几何平均。
- 置信区间用 association_group 聚类 bootstrap：2000 次重抽样，rng 20261106，1296 个组。
- C2 和 C3 的各类召回包含后段 hover 的故障窗口。

**前置门**：两项都已通过。

- GBT 的折向量与 T 组外层折逐窗一致。
- T0 在 seed 42/43/44 上的 FP 分别为 3595/3588/4610，与 T 组的数值一致。

## 解读

1. **ENS 在 T0 基线、5 个 seed、R97 工作点下依然成立，而且幅度很大：误报减半（比值约 0.45–0.48）**。匹配误报下，每一类召回都上升 0.4–8.3 pp；AP 的置信区间整体大于 0。改善覆盖除 circling 以外的全部飞行类型的后段。
2. **单独的 GBT 已经贡献了几乎全部收益**（比值 0.497）。叠加 MSTCA 后只再多降约 3–9%。
3. 失败原因和 T 组、V 组一样，都是 C3 上的 GPS。R97 是对全部故障合并计算的召回点：模型在其他类上整体变好后，R97 阈值随之上移，最难分的后段 hover GPS 故障窗口就被让出去了。11-05 的 `hover_separability` 已经说明，后段 hover 的 GPS 在简单统计特征上区分能力弱；11-05 的 `feature_groupcv` 也是在这一块没有通过。
4. 这是第三次出现同一种情况（T1、V、E 都是除 C3 的 GPS 外全部通过，并且匹配误报下每一类都更好）。这说明需要决定的已经不是换哪个模型，而是**工作点如何定义**，以及**后段 hover GPS 的召回要求**定在多少。这属于协议层面的决定，不能根据本轮结果事后修改本轮判据。

## 边界

- 结论只来自 train CV，GBT 是单次拟合（random_state 0）。val 已经用过两次，内部 test 和 Real 都已加锁，所以没有干净的确认集。
- 11-06 的事件级结果显示，ENS 的分数分布与 M0 不同，窗口级的收益不能直接外推到事件规则。
- 在 Real 上，ENS 与 M0 一样失败（`real_event_eval_v1`）。

## 补充（事后，不属于冻结判据）：各类召回都不低于 T0 时的误报

对每个 seed，先算出 T0 在 R97 阈值下每一类的召回（包含后段 hover 窗口）。再给每个臂取最高的阈值，使它每一类的召回都不低于 T0 的对应值，然后统计这个阈值下的 FP。

这个口径问的是："保证每一类都检出得不比 T0 少，误报能降多少？"

| 臂 | 5 个 seed 的 FP | 比值（几何平均） | 起约束作用的类 |
|---|---|---:|---|
| T1 | 3222 / 3138 / 3271 / 3381 / 3170 | 0.822 | GPS、magnetometer |
| GBT | 2520 / 2352 / 2928 / 2282 / 2489 | 0.636 | GPS、barometer |
| E0 | 2371 / 2298 / 2823 / 2281 / 2479 | 0.621 | GPS、barometer |
| E1 | 2461 / 2160 / 2638 / 2166 / 2223 | 0.590 | GPS、barometer |

T0 的 5 个 seed 的 FP 为 3595 / 3588 / 4610 / 3740 / 4243。

即使要求每一类（包括后段 hover 的 GPS）都不比 T0 差，ENS 仍能把误报降低约 40%。这个口径是看过本轮结果之后才提出的，只能作为下一份协议的候选，并且须在 CV 已经被看过的前提下如实披露。
