## 1. 用户决定（2026-11-08）

- **源域最终检测模型：GBT**
  - 输入：130 维窗口统计。
  - 模型：HistGB，max_iter 400，lr 0.05，max_leaf_nodes 31，l2 1.0，random_state 0，类别均衡样本权重。
  - 部署拟合：`artifacts/ens_internal_test_v1_20261105/gbt_full_train.pkl`，全量 train 拟合，sha256 df468524…，本地存在。
- **后续跨域研究的深度特征骨干：T1 MSTCA**，即纯 26 通道、固定 100 轮。现阶段它不承担检测任务。
- **工作点**：严格逐类召回不低于基线。后段 hover mode 4 GPS 不作硬约束，包括 26 通道不可观测的 z≠1 和在 hover 中没有有效物理效应的 z=1/恒等。依据见 Q1、Q2 报告。

## 2. 工作点定义（冻结）

- **基线**：T0，seed 42–46。每个 seed 以 T0 自己的 FP@R97 阈值为参照，记录各约束层的 TP 数作为目标。
- **约束层（7 个）**：
  - GPS（去掉后段 hover mode 4 的窗口）；
  - 加速度计、气压计、陀螺、磁力计、电机；
  - 后段 hover GPS mode 3。
- **排除的窗口**：798 个，36 个案例。这些窗口只做披露，不参与约束。
- **阈值规则**：
  - 先对每个 seed 求出 GBT 能满足该 seed 全部 7 个目标的最高阈值；
  - **部署阈值取 5 个 seed 中的最小值**，保证召回不低于每一个 T0 seed。
- **判据**：
  - A1：误报比值的几何均值 < 1，且 bootstrap CI 上界 < 1。
  - A2：OOF 阈值迁移时，7 层召回相对 T0 的亏损都不超过 1 pp（按 seed 均值）。
- **失败处理**：如实报告。本轮不改定义，也不换模型。

## 3. 结果

**哪个约束在起作用**：
- 部署阈值来自 seed 44 的**气压计**目标。T0 seed 44 的气压计召回是 0.9649，在 5 个 seed 中最高。
- 按单层分别计算 seed 44 的阈值，误报分别为：气压计 2928、后段 GPS mode 3 2779、GPS 2402，其余更低。
- 在 5 个 seed 中，有 4 个 seed 的最紧约束是气压计。

  - seed 均值：+0.29 到 +12.6 pp；

## 4. 结论

1. **A1 未通过。** 点估计 0.744，5/5 个 seed 都 < 1，但 CI 上界 1.018。原因有三：
   - “对每个 T0 seed 都不低于”取的是 5 个 seed 中最好的那个 T0，seed 44 的气压计召回 0.9649 决定了阈值；
   - 这一项在 bootstrap 中波动大；
   - 部署阈值是 5 个 seed 阈值的最小值，本身就是取极值。
2. **A2 通过**，而且是显著的余量：OOF 迁移后，各层召回不仅不低于 T0，还明显更高；误报比值 0.80。
3. 按冻结的失败处理，**本轮不改定义、不换模型**。GBT 作为源域检测模型的决定不受影响，那是用户的决定；但部署阈值 0.3744 在 train-CV 上的误报优势，不能写成“已统计确认”，只能写成“点估计降低约 26%，所有 seed 方向一致，CI 上界略超过 1”。
