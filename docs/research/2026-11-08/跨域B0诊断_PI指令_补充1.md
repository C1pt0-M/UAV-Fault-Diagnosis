# PI 指令补充 1：B0-1 敏感性分析的口径

> 依据：`configs/experiments/real_v2_b0_diagnostics.json` 与 `跨域B0诊断_PI指令_v1.md`，两者都不变。本补充在任何 Real npz 打开、任何 B0 指标计算之前发出，只澄清口径，不改判据。

## 结论：采用 B（只筛评估子集，不重新训练）

- 沿用 B0-1 主分析的 5 折 OOF 概率，不重新训练；
- 评估时，负类只保留 `window_end_row ≤ fault_onset_row − 250` 的 pre_fault 窗口，正类不变；
- 用同一 OOF 概率计算 AUC，并给出关联组聚类 bootstrap CI（2000 次，rng 20261108，与主分析一致）；
- 同时报告被筛掉的近起点负类窗口数和案例数，以及它们单独与正类比较的 AUC（描述性）。

## 理由

敏感性分析要回答的是：主分析的 AUC 是否主要由靠近故障起点、可能已带早期故障迹象的窗口贡献。只换评估子集、不换模型，可以直接回答这个问题；重新训练会同时改变模型，两种变化混在一起，没法区分。
