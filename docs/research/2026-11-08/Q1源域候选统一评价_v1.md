## 1. 问题与边界

- **问题**：在“每类故障召回都不低于 T0 基线”的工作点下，现有哪个源域候选的正常误报最低？应该保留哪一个作为稳定源域模型？
- **数据**：只用 train 3 折 group-CV 的 held-out 预测，共 162069 个窗口，折号为 sha256('h1cv|'+association_group)%3。没有读取 val、内部 test 或 Real。
- **没有重新训练**。所有候选的预测都已有：T（t_selection）、W（w_phase_balance）、S（s_ablation）、GBT（feature_groupcv gbt_heldout）。
- **披露**：
  - T1、GBT、E0、E1 在这个工作点下的结果已在 E 组补充分析里看过。
  - train-CV 总体已被反复分析。
  - 因此本结果只是**候选选择**，不是独立确认。

## 2. 方法（与协议一致）

- **T0 参照**：每个 seed 取 T0 自己的 FP@R97 阈值，记录这个阈值下 6 类故障各自的 TP 数 r0[c]。
- **主工作点（per-class）**：对每个候选和每个 seed，取能让 6 类 TP 都不低于同 seed T0 的 r0[c] 的最高阈值。在这个阈值下数正常窗口的误报，记为 FP_pc。
- **strict 变体**：在 6 类之外，再把“后段 hover GPS”（hover 飞行、window_end_row×0.02 > 30 s）作为第 7 个约束层。
- **主指标**：各 seed 的 FP_pc(候选)/FP(T0) 比值，再取几何均值。
- **置信区间**：association_group 整群 bootstrap，2000 次，rng 20261106，共 1296 组。每次重采样都重新计算 T0 阈值和逐类目标。
- **门控检查通过**：
  - T0 FP@R97（seed 42–46）= 3595 / 3588 / 4610 / 3740 / 4243；
  - S0 best（seed 42–44）= 3595 / 3588 / 4610，与 T0 一致。

### 3.2 按冻结规则选择

1. **合格**（比值 < 1、所有 seed < 1、CI 上界 < 1）：E1、W1+GBT、W2+GBT、E0、GBT、S2+GBT、S1+GBT、S3+GBT、T1。
2. **最佳**：E1（0.590）。
3. **简约检查**（成对 bootstrap，共同 seed 42–46）：
   - E1/T1 = 0.718 [0.624, 0.887]：E1 明显优于 T1。
   - E1/GBT = 0.927 [0.829, **1.0014**]：CI 上界 ≥ 1，按规则**保留单模型 GBT**。
4. **flags**：无。strict 比值都 < 1；没有类别 OOF 亏损 > 1 pp；GBT 有 5 个 seed，不触发 3-seed 标记。

**冻结规则结论：KEEP = GBT。** E1 点估计最好，但相对 GBT 的优势在主工作点上没有达到冻结的统计门槛：上界 1.0014，只差一点。

## 4. 结论

1. **GBT 类候选全面优于纯 MSTCA**。GBT、E0、E1、W+GBT、S+GBT 的误报比值都在 0.59–0.68，T1 为 0.82。
2. **W 和 S 没有带来增益**：
   - W1、W2、S1、S2、S3 单独使用都不合格，比值 1.03–1.26。
   - 进入 GBT 集成后也不优于 E1：E1/W1+GBT 为 0.989，S2+GBT/E1 为 1.04。
   - 与此前 W、S 组结论一致，不再继续这两个方向。
3. **按冻结规则保留 GBT**。E1 与 GBT 在主工作点上不可区分。E1 的描述性优势体现在 strict 变体上：把后段 hover GPS 也纳入约束时，E1/GBT = 0.919 [0.856, 0.951]，这正是 GBT 单独使用时最弱的地方（strict CI 上界 0.994）。
4. **共同弱点**：所有含 GBT 的候选，在主工作点下的后段 hover GPS 召回都比 T0 低约 8–12 pp（OOF 为 −5 到 −8 pp）。纯 MSTCA 候选没有这个问题，但误报高得多。后段 hover GPS 的可检出性由 Q2 回答：其中 mode 4 主体在 26 通道里本身不可观测。

## 5. 需要用户决定的事项

冻结规则给出 **GBT**。是否改选 **E1**，取决于下面两点，属于用户的研究取舍，本报告不替用户决定：
- 后段 hover GPS 是否作为约束：如果保留 strict 约束，E1 显著优于 GBT。
- 后续跨域适配是否需要深度模型分支：E1 含 MSTCA，可以做特征级适配；纯 GBT 不行。

## 6. 注意事项与偏差

- **bootstrap CI 不对称**：点估计靠近下界。原因是逐类约束取的是多个带噪 TP 目标中最紧的一个，重采样时会偏向更紧，比值整体偏高。CI 上界因此偏保守。
- **GBT 的训练随机性没有计入**：
  - GBT 是单次拟合（random_state 0）。HistGB 的 early_stopping='auto' 在 n > 10000 时启用，random_state 会影响结果。
  - 所以 GBT 的“5 个 seed”只反映 T0 参照的随机性，不反映 GBT 自身的随机性。E 系列的 seed 只反映 MSTCA 部分的随机性。
- **S 组只有 seed 42–44**。S 的 best 权重沿用原 S 组规则选点。
- **与协议的偏差**：无。附加的描述性成对比较在主结果之后计算，已在 3.3 标明，不参与选择。
