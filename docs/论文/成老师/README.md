## 目录和文件用途

```text
成老师/
├─ 三篇原始 PDF（保留原名）
├─ README.md                 本索引
├─ 三篇论文全文精读与项目对照.md
└─ MinerU/
   ├─ FS-PTL/
   ├─ R3PTL/
   └─ LOODG/
```

每篇提取目录中：

- `full.md`：可直接阅读的全文，包含 LaTeX 公式、表格及图片引用。
- `images/`：MinerU 返回的图像及版面裁切，不应把文件数量直接视为论文图数。
- `*_content_list.json`、`*_content_list_v2.json`：结构化内容块，供定位文字、表格、图片和页面使用；页索引从 0 开始。
- `*_model.json`、`layout.json`：MinerU 的结构与版面输出。
- `*_origin.pdf`：服务返回的 PDF 产物。三份均与外层输入 PDF 的字节哈希不同，不能代替外层原文件做原件身份校验；引用原始来源时仍用外层 PDF。
