# 13维候选特征：已有证据、缺口与后续判断

日期：2026-11-01。依据[暂定研究主线v2](model_research_direction_v2.md)整理。**本轮仅重汇总已保存证据并核对现有源码，没有新增故障／正常实验，没有读取原始日志、训练缓存或最终test／Real，没有模型加载／推理、GPU使用、统计拟合、公式修改或Git推送。**

## 1. 当前可以确认什么

1. 已明确13个候选的身份：旧九项z空间统计代理O1–O9，加上有符号垂向残差N1和三维姿态残差N2–N4。不是把15项旧诊断结果直接改名为13维。
2. 13项都有计算实现和有限源开发数据证据；旧九维已复用原公式，新四维有合成已知答案及因果发布流核验。物理语义严谨程度不同，不能统一称13个物理残差。
3. 在固定hover案例内，部分旧特征有明显阶段变化，也保留一些故障排序信息；新四维定义明确，但分量、域及故障目录之间响应不统一。
4. **13项相对当前26通道纯MSTCA的增量价值全部未知。**没有任何一项已通过当前协议的受控加入／移除对照。没有GPU不妨碍本次整理，但不能用现有单量AUC替代训练增益证据。
5. 当前不作最终保留／删除名单，不排名、不打一个掩盖不同缺口的总分、不拟定新的筛选阈值。所有13项状态均为“候选，未决”。

## 3. 13项身份与公式语义

下面z表示当前冻结源train逐通道标准化值；u为4控制槽，o为4输出槽。旧九项std均为population std（unbiased=False）。新四维在物理单位计算，不在z空间套运动学公式。

|ID／键名|现有公式或定义|可以成立的解释|主要语义缺口|
|---|---|---|---|
|O1 old_output_std|std(o1,o2,o3,o4)|标准化输出槽离散度|各槽独立标准化；不是原PWM离散，更不是实测转速／推力不平衡|
|O2 old_output_range|max(o)−min(o)|标准化输出槽极差|对单槽极值敏感，没有独立物理约束意义|
|O3 old_ctrl_output_gap_mean|mean_i(abs(u_i−o_i))|固定配对后的数值差均值|roll/pitch/yaw/throttle控制槽不是四个电机目标；逐索引不等于混控后的指令跟踪|
|O4 old_ctrl_output_gap_std|std_i(abs(u_i−o_i))|上述数值差的离散度|继承O3语义不匹配；不能称执行器一致性残差|
|O5 old_effort|mean(concat(u,o))/max(z_acc_norm,0.1)|人工截断比值|分母是标准化加速度模，负值也被截到0.1；非物理推力／能量／效率|
|O6 old_acc_deviation|abs(z_acc_norm)|加速度模偏离源train总体均值的标准差倍数|不是abs(norm(a)−g)；基础26通道已有acc_norm|
|O7 old_gyro_norm|norm(z_gyro_xyz)|标准化角速度活动程度|不是rad/s物理模，正常旋转也会改变它|
|O8 old_vertical_consistency|abs(diff(z_baro,prepend=first)−z_vel_z)|历史垂向混合代理|未除dt，独立尺度、NED方向未统一，ZOH差分与异步影响；不称物理一致性|
|O9 old_attitude_energy|norm(z_q_xyz)|标准化四元数xyz分量统计|不是姿态能量；不再是单位四元数几何，不保证对q/-q标准化变换不变|
|N1 rh_signed_m|h_av(t)−h_av(t−0.2)+∫vz_av ds|有符号垂向发布流一致性，m|异步、滤波／共享估计、reset仍影响；自洽的异常运动可残差很小|
|N2 rR_x_rad|Log(R_hat.T R_end).vee_x|姿态积分误差x分量，rad|不是某轴故障标签，受误差表达参考系、初姿态和多轴运动影响|
|N3 rR_y_rad|同一姿态积分误差的y分量|同上，rad|与N2共享计算／验证，不能当成独立方法证据|
|N4 rR_z_rad|同一姿态积分误差的z分量|同上，rad|方向和背景依赖明显，不能只用姿态范数代替检查|

姿态积分固定R_hat=R_start·product(exp([omega_body·actual_dt]x))，Hamilton wxyz、FRD到NED，右乘；原生可用时间变化点ZOH积分，近零／非有限／范数溢出四元数拒绝，合法四元数归一化，q/-q旋转等价已核验。

**四维候选不是**rh_abs_m与rR_norm_rad：这两个幅值量只作为已有诊断辅助，不计入13维。它们也不能替代有符号分量的证据。若以后选择绝对值、范数或改公式，需要显式新增／替换版本和理由，而不是悄改候选身份。

旧九项都是同一26通道的确定性变换；收益若有，主要是有限模型／样本下的表征和归纳偏置，不是额外传感器信息。新四维还使用原生消息可用时间／跨度信息，不能声称只靠既有26×150张量就完全恢复。

## 6. 数据有效性：已有保障与具体缺口

### 6.1 旧九维共性

已知：继承当前基础26通道的因果采样和原资格规则；在E3中对2072个共同有效窗执行原函数，得到有限9×150结果，再对后140位置摘要。108个代表窗的独立NumPy实现与Torch旧公式最大差约9.54e-7，支持计算复现。

未知：这不是九个候选在全部train、全部运行状态的逐项异常分布认证，也没有证明跨话题同时观测。有限、不含NaN不等于物理有效。O3–O5和O8跨话题组合尤其要保留异步背景；不把它们的“算得出来”改写为“同步一致性通过”。

具体尚缺：O1/O2单槽极端值及冗余；O3/O4槽位语义与背景影响；O5截断占比和尾部；O6/O7正常机动条件分布；O8异步和ZOH影响；O9标准化后的q符号／姿态参考依赖。当前未追加这些扫描。

### 6.2 新四维共性

已知：固定0.2s时域、原生可用时间段积分、跨度中间年龄／invalid检查、reset／设备变化mask、四元数合法性、未来前缀不变与逐窗前10帧不可用均已测试。

- 正常12锚点：原可监督760窗、共同全140位置有效707窗，53窗新增限制不改主缓存。
- 固定36例：原准入2258窗、共同2072窗，186窗新增限制约8.24%，不能当作模型低误报收益。前后资格口径不同，53和186不能相加。
- 正常12锚点有效端点垂向观测时差均值27.51ms、P95 60.18ms；姿态／gyro均值12.60ms、P95 44ms。相对200ms跨度不可忽略，仍是发布回放流定义而不是同步观测认证。
- 正常姿态组最大范数约0.19693rad（约11.28度）保留，所核计数未跨reset，原因未定；不能凭峰值改标签、删样本或将该组无条件判故障。该峰值是三分量范数，不是每个分量都达到该值。

未知：新增资格在全部工况／故障类型的覆盖偏差；同步误差、估计共享依赖与真实不一致的贡献；故障瞬间短暂响应；原生消息读取用于训练的可复现接入和有效mask合同。没有拟合残差训练归一化，既有340窗IQR不得偷作训练参数。

## 8. 已知信息能怎样减少后续工作量

无GPU期间，本轮已完成证据编目，而不是再新增13个实验。优先级是**解决判断缺口**，不是给候选排性能名次：

1. 所有项先保留精确公式版本。O3/O4/O5/O8/O9纠正强物理解释，不擅自改公式；如果另提修正版，必须另记新候选，避免池子无声膨胀。
2. 数据接入先决定新四维的140有效域与mask方式，以及是否可接受原生时间依赖；M0既要保留全基础覆盖结果，又要有同原ID／同有效时域对照，不能靠少测8.24%的难窗显示改进。
3. 对13项的条件依赖，优先明确可因果获得的窗口运行状态定义。不要按目录把hover全当稳态，也不把原裁剪分位当线上工况标签。具体进一步CPU分析若有必要，应另列小范围和问题，不自动扩查整库。
4. 以后GPU可用且确认执行时，优先建立M0。旧九维本来是26通道的确定性变换，单量表现强也可能是M0已学到的信息；有无增量只能在受控比较中回答。
5. 特征筛选限定在源train组内开发和既定val确认，不穷举2^13、不将同批已暴露val当新盲测、不用最终test／Real选子集或翻方向。只在增量证据出现后才讨论最终入选。

暂不追加GPU任务、拟合新统计、训练单特征分类器、自动删除任何通道或候选。M4的条件正常行为建模仍是独立方法主线，不被13维整理绑成“必须全部选完才能研究”。
