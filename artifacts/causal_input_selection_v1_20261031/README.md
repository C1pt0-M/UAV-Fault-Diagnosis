# 已应用的小规模输入筛选

本次16份源日志中5份有局部窗口不可用，没有整份不可用文件。按此前固定的因果输入年龄预算，214个窗口从可用输入清单排除，保留7729个；原文件、时间轴、窗口ID和train／val划分未改。

原因是窗口内至少一帧必要观测过旧；不能靠未来观测插值补齐来宣称实时可用。不能据此认定整段飞行无效。

包含清单included_input_windows.csv；排除及原因清单excluded_input_windows.csv；逐例汇总case_selection_summary.csv。原始排除记录完整保留，不重抽或改阈值。

范围仅此前16例小规模试验，不是全库清洗计数。输入可用不等于标签资格或真实接收链路通过，未授权训练或物理删除。
